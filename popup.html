      External services

      When enabled, scans send the site hostname to SSL Labs, VirusTotal, and Google Public DNS, and the site origin to Google Safe Browsing. SSL Labs may actively test the public server. URL paths, queries, fragments, form values, and page contents are not sent. These providers receive your IP address. Local/private hostnames and literal private IP ranges are excluded; DNS resolution is not used to verify public routing.

      Keys stay in local extension storage and go only to their provider. They are never included in reports.

      Checks to run

      Directory probing sends unauthenticated GET requests to common paths. Enable it only for sites you are authorized to test. Finding an accessible page alone is not a directory exposure.
